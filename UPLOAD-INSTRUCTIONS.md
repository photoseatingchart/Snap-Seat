# Publish the updated guest controller

Upload these four files from this ZIP to the same GitHub Pages folder that currently serves `Snap-Seat` (the repository root, if Pages still uses its root source):

- `index.html`
- `controller.js`
- `style.css`
- `drawing-reveal.js`

On the repository website, open `photoseatingchart/Snap-Seat`, choose **Add file → Upload files**, drag in those four files, and commit the changes to the branch/folder configured under **Settings → Pages**. The inspected repository used its root folder. Keep the existing `config.js` and every unrelated file; do not upload any Supabase secret or Host PIN. Wait for Pages to deploy, then open `https://photoseatingchart.github.io/Snap-Seat/`.

The GitHub connection available during this work was read-only, so these files have not been published. After updating Pages, restart the PC event session so its QR uses the current guest page.
